# Настройка рабочей среды для Python-разработки

## Описание проекта

Данный проект создан в рамках выполнения задания по настройке рабочей среды для разработки на Python. В процессе работы были выполнены следующие шаги:

- Установка WSL (Ubuntu)
- Установка и настройка Visual Studio Code
- Установка необходимых расширений для VS Code
- Настройка Git и подключение к GitHub
- Создание базовой структуры проекта
- Написание простейшей программы на Python
- Загрузка проекта в публичный репозиторий GitHub
